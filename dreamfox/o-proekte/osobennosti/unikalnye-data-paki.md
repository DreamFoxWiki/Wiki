# Уникальные дата-паки

## Дроп с мобов <img src="../../.gitbook/assets/image (659).png" alt="" data-size="line">

На нашем сервере есть два моба, с которых выпадает особый лут!

**Кадавр** <img src="../../.gitbook/assets/image (660).png" alt="" data-size="original">

{% hint style="warning" icon="tombstone" %}
При убийстве с кадавра выпадает песок. Количество песка увеличивается с зачарованием добыча:

Добыча I — 1-4 блока\
Добыча II — 1-7 блоков\
Добыча III — 1-10 блоков
{% endhint %}

**Хранитель** ![](<../../.gitbook/assets/image (661).png>)

{% hint style="info" icon="book-bookmark" %}
При победе над хранителем с шансом 5% можно получить книгу на проворство. За каждый уровень зачарования добыча шанс на выпадение меняется следующим образом:&#x20;

Добыча I — 6.7%\
Добыча II — 8.4%\
Добыча III — 10.1%
{% endhint %}
