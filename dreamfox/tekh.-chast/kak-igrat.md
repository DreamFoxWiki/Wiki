# Как играть?

{% hint style="success" %}
Чтобы войти на сервер, вам понадобится лаунчер игры. Если у вас нет официального, можете использовать TL Legacy. Переходим по ссылке и скачиваем нужный нам файл. После того как Вы установили и настроили лаунчер, заходите в игру с версии сезона, далее сетевая игра, добавить, и в адресе сервера введите \
**dreamfox.fun** - IP сервера ![:dreamfox:](https://cdn.discordapp.com/emojis/959086521896542238.webp?size=44\&quality=lossless)\
Ссылка на лаунчер: [https://tlaun.ch/exe](https://tlaun.ch/exe)
{% endhint %}
